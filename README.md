# Microprocessor & Microcontroller Lab Terminal (Command Prompt)

An interactive, browser-based Windows Command Prompt simulation loaded with 8085 Assembly & 8051 Keil C practical questions & programs.

## 🚀 Live Domains
- **Primary Domain:** [https://dbmscmd.surge.sh](https://dbmscmd.surge.sh)
- **GitHub Pages Mirror:** [https://sairamssss.github.io/dbmscmd/](https://sairamssss.github.io/dbmscmd/)

## 🛠 Commands
- `1` through `20` — Display practical code and solution
- `ls` / `dir` / `help` — List all 20 questions in an ASCII table
- `cp <1-20>` — Copy code for specific question to clipboard
- `all` — Display all 20 questions sequentially
- `cls` / `clear` — Clear terminal screen
