# Lab Terminal (Command Prompt)

An interactive, browser-based Command Prompt simulation.

## 🚀 Live Domains
- **Primary Domain:** [https://dbmscmd.surge.sh](https://dbmscmd.surge.sh)
- **GitHub Pages Mirror:** [https://sairamssss.github.io/dbmscmd/](https://sairamssss.github.io/dbmscmd/)

## 🛠 Features
- Classic Windows Command Prompt styling (`python -i` / interactive lab terminal)
- Interactive command execution and simulations
- Fully self-contained client-side application built with HTML, Tailwind CSS, and vanilla JavaScript
