# 8085 & 8051 Practical Lab Terminal (Command Prompt)

An interactive, browser-based Windows Command Prompt simulation containing all 20 questions and 40 subdivisions directly from the official **8085 & 8051 Practical Questions with Answers** document.

## 🚀 Live Domains
- **Primary Domain:** [https://dbmscmd.surge.sh](https://dbmscmd.surge.sh)
- **GitHub Pages Mirror:** [https://sairamssss.github.io/dbmscmd/](https://sairamssss.github.io/dbmscmd/)

## 🛠 Commands
- `1` through `20` — Display question with both subdivisions `(i)` and `(ii)` in separate cards, each with its own `[Copy]` button.
- `1a` or `1i` — Display subdivision `(i)` only.
- `1b` or `1ii` — Display subdivision `(ii)` only.
- `cp 1a` or `cp 1i` — Copy subdivision `(i)` code directly to clipboard.
- `cp 1b` or `cp 1ii` — Copy subdivision `(ii)` code directly to clipboard.
- `cp 1` — Copy both subdivisions of question 1.
- `ls` / `dir` / `help` — View formatted ASCII table listing all 20 questions and subdivisions.
- `all` — Display all 20 questions sequentially.
- `cls` / `clear` — Clear terminal screen.
