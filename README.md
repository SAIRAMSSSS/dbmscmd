# DBMS Lab Terminal (Command Prompt)

An interactive, browser-based MySQL Command Prompt simulation designed for DBMS lab practice.

## 🚀 Live Demo
- **GitHub Pages:** [https://sairamssss.github.io/dbmscmd/](https://sairamssss.github.io/dbmscmd/)

## 🛠 Features
- Classic Windows Command Prompt styling (`mysql -u root -p`)
- Interactive SQL query execution and schema simulations
- Fully self-contained client-side application built with HTML, Tailwind CSS, and vanilla JavaScript
